# Unsonet

**Independent software company building products, platforms, infrastructure, and open-source technology.**

Unsonet is a software ecosystem built around a simple idea: **build the infrastructure you need, turn useful experiments into products, and open as much of the technology as possible.**

Our repositories range from small developer utilities to large libraries and the core technologies behind our products.

## Products & Platforms

### Excelsior

A browser-based platform for running and distributing mini-applications.

Excelsior turns scripts, scrapers, crawlers, bots, utilities, and other small applications into accessible browser-based tools.

### Excelsior PDF

A JavaScript/TypeScript PDF table extraction engine for browsers and Node.js.

It is designed to reconstruct structured tabular data from real-world PDFs, including tables with borders, tables without borders, merged cells, headers, watermarks, and other difficult layouts.

No OCR or neural networks are required.

### Wave

A browser-based audio platform combining the ideas of a music player, DAW, and real-time audio processing environment.

Wave is built around modular DSP processing and a programmable audio graph, with the long-term goal of making advanced audio processing accessible directly from the browser.

### Wave Shifter

A browser extension and audio-processing technology project that provides real-time pitch shifting, time stretching, equalization, effects, and other DSP processing directly in the browser.

Wave Shifter is also one of the technological foundations behind Wave.

### Unsobot

An AI/LLM platform for working with multiple language models and large amounts of data.

The project focuses on practical AI workflows, model integration, automation, and processing rather than tying the entire system to a single model provider.

### Ethnic Translator

A multilingual translation platform focused on practical machine and AI-assisted translation.

### Ethnic Foundation

The linguistic data and supporting infrastructure behind Ethnic Translator.

### Unsonet Hosting

Our own application hosting and infrastructure layer for SPAs, SSR applications, APIs, static websites, custom domains, HTTPS, shared assets, and multi-application deployments.

It was built to eliminate the need to maintain a separate infrastructure stack for every small application and project.

### Stacksale

Infrastructure for the internal economy and marketing systems of Unsonet applications.

It provides building blocks for virtual currencies, offers, plans, rewards, promo codes, referrals, advertising spaces, and cross-project promotions.

## Engineering Philosophy

We prefer **building technology over assembling dependencies**.

That means creating our own solutions when existing software does not provide the required control, performance, architecture, or flexibility.

Our projects commonly involve:

* TypeScript / JavaScript
* Angular
* Node.js
* Web APIs
* WebAssembly
* Web Audio API
* AudioWorklets
* Browser Extensions
* SSR
* APIs and distributed services
* AI / LLM integration
* PDF processing
* Web scraping and automation
* Custom build systems
* Performance optimization
* Security and browser platform engineering

We care about the underlying architecture.

A workaround that hides the problem is usually less valuable than fixing the model that caused it.

## One Ecosystem, Many Projects

The repositories in this organization are not isolated projects.

A small library may become a component of a larger application.

An experimental project may become the foundation of a future product.

A product may expose infrastructure that is later reused by other products.

This creates a continuous cycle:

**Experiment → Library → Infrastructure → Product → Open Source**

That is one of the main reasons the Unsonet repository count keeps growing.

---

## Why Open Source?

Not everything we build needs to be proprietary.

Publishing our libraries makes them easier to inspect, reuse, improve, and integrate with other projects.

It also gives us something more valuable than a private codebase: **real-world feedback from developers using the technology outside our own environment.**

Some of our most interesting engineering problems started as internal requirements and eventually became independent open-source projects.
